# Architecture Decision Records

Este diretório contém as decisões arquiteturais da SmartBiz Enterprise.

## Status possíveis

- Proposto
- Aceito
- Substituído
- Rejeitado
- Descontinuado

## Regras

1. ADRs aceitos não devem ser apagados.
2. Uma decisão alterada deverá ser substituída por outro ADR.
3. O novo ADR deverá informar qual decisão anterior substitui.
4. Toda decisão relevante para Web, API, Android ou iOS deverá ser documentada.
5. Mudanças incompatíveis em contratos públicos exigem análise arquitetural.
